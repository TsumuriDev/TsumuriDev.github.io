## 🚀 Cách mở và triển khai (Deploy)
- **Chạy thử trên máy:** Nhấp đúp vào [`index.html`](index.html) để mở bằng bất kỳ trình duyệt nào.
- **Đưa lên mạng miễn phí (Vercel / GitHub Pages):**
  1. Đẩy thư mục này lên GitHub cá nhân `https://github.com/TsumuriDev/<repo-name>`.
  2. Bật **GitHub Pages** trong Settings -> Pages -> Chọn branch `main` -> Xong!
  3. Hoặc liên kết repo với **Vercel** / **Cloudflare Pages** để có link `zoemc` hoặc tên miền riêng tùy ý.
